## About

I work at the intersection of formal verification, quantum-safe systems, and applied control theory — building things where correctness is proven, not assumed. Currently exploring verified agentic AI and post-quantum cryptography.

## Projects

**[TrustLoop](https://github.com/UNIT-O1)** — Formal verification pipeline
A multi-layer execution pipeline for AI-generated code. Uses Z3 SMT solvers and property-based testing (Hypothesis) to prove logical correctness across infinite input spaces.

**[Bajaj OHM](https://github.com/UNIT-O1)** — Active torque vectoring · *National Winner, 2nd Runner-up*
Software-driven differential for L5 electric vehicles. A 3-DOF vehicle model with independent rear hub motors, controlled via active sliding mode control for precision yaw handling.

**[QuMail](https://github.com/UNIT-O1)** — Quantum-secure communication layer
Post-quantum messaging platform integrating lattice-based signcryption and quantum key distribution.

**[XNAV](https://github.com/UNIT-O1)** — Pulsar-based deep-space navigation
Autonomous spacecraft positioning using an Extended Kalman Filter over X-ray pulsar timing — no Earth-bound GPS required.

**[DishRight](https://github.com/UNIT-O1)** — AI-assisted cooking interface
A high-density, minimalist UI built for decision-making under constraints.
