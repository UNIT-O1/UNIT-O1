### ▰ THE CATALOG (PROJECTS)

> **[ 🧠 TrustLoop | Formal Verification Pipeline ]** <br>
> *From Assumption to Assurance.* A multi-layer execution pipeline for AI-generated code. Utilizing **Z3 SMT Solvers** and **Property-Based Testing (Hypothesis)** to detect edge cases and prove logical correctness across infinite input spaces.

> **[ 🏎️ Bajaj OHM | Active Torque Vectoring ]** <br>
> *National Winner & 2nd Runner-up.* Developed a software-driven differential for L5 Electric Vehicles. Implemented a **3-DOF vehicle model** with independent rear hub motors and **Active Sliding Mode Control (ASMC)** for precision yaw control.

> **[ 🔐 QuMail | Quantum-Secure Layer ]** <br>
> A communication platform designed for the post-quantum era. Integrates **Lattice-Based Signcryption** and **Quantum Key Distribution (QKD)** to ensure data integrity against future cryptographic threats.

> **[ 🛰️ XNAV | Pulsar-Based Navigation ]** <br>
> An autonomous deep-space positioning system. Built with an **Extended Kalman Filter (EKF)** to estimate spacecraft coordinates using X-ray pulsar timing, eliminating the need for Earth-bound GPS.

> **[ 🍳 DishRight | AI UI/UX ]** <br>
> A high-density, minimalist cooking interface designed for decision-making under constraints. Focuses on user-centric design flows and sleek, functional prototyping.
